# Kamesh M P — Portfolio

Static portfolio website for GitHub Pages.

## Deploy
1. Create a GitHub repository named `kameshmp.github.io`.
2. Upload `index.html` and `Kamesh_M_P_Resume.pdf`.
3. In Settings → Pages, select the main branch and root folder.
4. Your site will be available at `https://kameshmp.github.io/`.

Replace `Kamesh_M_P_Resume.pdf` with your final resume PDF.
